OpenEverest introduces Plugin Bench, a new plugin that brings containerized performance benchmarking into the platform. You can now define and manage benchmark jobs through the UI, run them asynchronously, and review metrics and status without leaving the console.

Previously, benchmarking had to be configured manually using separate tooling outside of OpenEverest, making it harder to tie results directly to specific database clusters.

Plugin Bench is available now as a Helm chart or an OCI chart from the Extension Hub. To learn more, visit the [Plugin Hub](https://docs.openeverest.io/).
