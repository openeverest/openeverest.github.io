The MariaDB provider now ships with an expanded library of default deployment presets, reducing the time needed to configure and launch new MariaDB clusters.

Previously, operators had to manually specify image versions, resource requests, and storage parameters for each new deployment. The additional presets cover more common workload profiles with sensible defaults out of the box.

Update to provider-mariadb v0.1.6 to access the new presets. Select one at creation time and tune as needed.
