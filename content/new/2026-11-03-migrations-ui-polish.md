The Migrations plugin UI gets several polish improvements that make day-to-day schema change management faster and clearer:

- **Pre-filled migration names** — new migrations get a random default name, so you can create one without stopping to invent a title.
- **Live status indicator** — the "Updated N seconds ago" label is replaced with a Live indicator that shows migration status at a glance.
- **Expandable Advanced options** — the Advanced section now displays a clear expand arrow, so the extra settings are easier to find.

These improvements ship in the Migrations plugin v0.1.0. To learn more, visit the [release notes](https://github.com/openeverest/plugin-migrations/releases/tag/v0.1.0).
