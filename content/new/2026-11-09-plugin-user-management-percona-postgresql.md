The User Management plugin now supports the Percona PostgreSQL provider, so users and roles on Percona PostgreSQL clusters can be managed from OpenEverest the same way as on any other supported engine.

Previously, Percona PostgreSQL clusters had to be administered out-of-band, with no central place to create users or grant access.

Percona PostgreSQL support is available now. To learn more, visit the [release notes](https://github.com/openeverest/plugin-user-management/releases/tag/v0.2.2).
