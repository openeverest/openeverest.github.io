The OpenEverest metrics plugin (v0.2.2) now includes a prebuilt dashboard for SeaweedFS, giving operators out-of-the-box visibility into their object storage clusters without having to build panels by hand.

The dashboard covers SeaweedFS components deployed through OpenEverest and appears automatically alongside the existing per-engine dashboards once the plugin is installed.

The dashboard is available in plugin-metrics 0.2.2. To learn more, visit the [release notes](https://github.com/openeverest/plugin-metrics/releases/tag/v0.2.2).
