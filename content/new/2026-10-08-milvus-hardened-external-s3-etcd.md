The Milvus provider now hardens external S3 object storage and external etcd
for production use. Milvus deployments backed by your own S3-compatible storage
and etcd get the configuration and validation needed for production workloads.

This makes bring-your-own storage and coordination a supported, production-ready
path instead of a best-effort setup.

To learn more, visit the
[release notes](https://github.com/openeverest/provider-milvus/releases/tag/v0.1.1).
