The MongoDB Explorer plugin can now display the full topology of a sharded MongoDB cluster — shards, config servers, and mongos routers — directly in the cluster overview.

Previously, the overview did not reflect the distinct roles that make up a sharded deployment, leaving operators to map them out manually. The topology view makes the structure of a sharded cluster immediately visible while browsing.

The update is available in the OpenEverest Plugin Hub. To learn more, see the [release notes](https://github.com/openeverest/plugin-mongodb-explorer/releases/tag/v0.1.19).
